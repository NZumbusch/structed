Last updated: {{LAST_UPDATED}}

In short: Structed runs entirely in your browser. There is no Structed server, no account, no analytics, no advertising and no tracking. Your content is stored on your device and – only if you choose to connect it – in a hidden app folder of your own Google Drive. The developer never receives, sees or stores your data.

2. Data stored on your device

Everything you create in Structed – projects, headings, texts, sources, quotes, paraphrases, notes, images, comments and snapshots – as well as your settings (theme, language, keyboard shortcuts, Zotero user ID and API key, Google client ID) is stored locally in your browser (IndexedDB and localStorage). This data does not leave your device unless you use one of the optional features below. It is not used for tracking. Browser storage is used only because it is technically necessary for the app to work (no consent required for strictly necessary storage).

You can delete all local data at any time in Settings → Backup & data → Delete all local data, or by clearing your browser’s site data.

3. Optional: Google Drive sync

If – and only if – you click “Connect Google Drive”, Structed uses Google Sign-In (Google Identity Services) to ask for your permission and then accesses the Google Drive API directly from your browser.

What Structed accesses

Structed cannot see, read, change or delete any other file in your Google Drive. Your data is sent only between your browser and Google’s servers; it is never sent to the developer or any other third party.

Optional: auth server (staying signed in)

Browser apps only receive Google access tokens that expire after about an hour. If an auth server URL is configured (a small Cloudflare Worker run by the developer, source code in the repository’s worker/ folder), Structed uses it to stay signed in: after you sign in, Google gives your browser a one-time code, which the auth server exchanges for an access token and a long-lived refresh token. Both are returned to your browser and stored only there. Later, your browser sends the refresh token to the auth server to obtain a new access token, and when you disconnect it asks the auth server to revoke access.

The auth server only handles these tokens – never your projects, quotes or any Drive content, which still travel directly between your browser and Google. It stores nothing and keeps no logs of its own. As the hosting provider, Cloudflare, Inc. processes technical request data such as your IP address to run the service; see the Cloudflare Privacy Policy. Without an auth server URL, no request goes to Cloudflare.

Google API Services User Data Policy

Structed’s use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. In particular, Google user data is used only to provide the sync feature you requested, is not used for advertising, is not sold, and is not read by humans.

Revoking access and deleting synced data

  • Disconnect in Settings → Sync → Disconnect (this also revokes the token).
  • Remove Structed’s access at any time at myaccount.google.com/connections.
  • Delete the hidden app data in Google Drive: drive.google.com → Settings (⚙) → Manage apps → Structed → Options → Delete hidden app data.

Google processes data according to the Google Privacy Policy.

4. Optional: Zotero

If you enter a Zotero user ID and API key, Structed sends requests directly from your browser to api.zotero.org to read your library, collections and annotations that you choose to import. Your key is stored only on your device and is not synced. See the Zotero privacy policy.

5. Hosting

The app’s files are served by GitHub Pages (GitHub, Inc.). When you load the site, GitHub processes technical data such as your IP address in server logs to deliver the pages securely; Structed has no access to these logs. See the GitHub Privacy Statement. After the first visit the app is cached on your device and works offline. No fonts, scripts or trackers are loaded from other third-party servers, except Google Sign-In when you connect Google Drive (and the optional auth server described above).

6. Legal basis (GDPR)

Where the GDPR applies: the optional Google Drive and Zotero connections are based on your consent and request (Art. 6(1)(a) and (b) GDPR); you can withdraw consent at any time by disconnecting. Delivery of the website by GitHub is based on the legitimate interest in providing a secure website (Art. 6(1)(f) GDPR).

Because the developer does not receive or store your data, you exercise most of these rights directly: export your data (Settings → Backup), edit it in the app, or delete it as described above. Optional: Auth-Server (angemeldet bleiben)

Browser-Apps erhalten von Google nur Zugriffstoken, die nach etwa einer Stunde ablaufen. Ist eine Auth-Server-URL eingerichtet (ein kleiner, vom Entwickler betriebener Cloudflare Worker, Quellcode im Ordner worker/ des Repositorys), nutzt Structed ihn, um angemeldet zu bleiben: Nach deiner Anmeldung erhält dein Browser von Google einen Einmal-Code, den der Auth-Server gegen ein Zugriffstoken und ein langlebiges Refresh-Token tauscht. Beide werden an deinen Browser zurückgegeben und nur dort gespeichert. Später sendet dein Browser das Refresh-Token an den Auth-Server, um ein neues Zugriffstoken zu erhalten; beim Trennen lässt er den Zugriff dort widerrufen.

Der Auth-Server verarbeitet ausschließlich diese Tokens – nie deine Projekte, Zitate oder sonstige Drive-Inhalte; diese werden weiterhin direkt zwischen deinem Browser und Google übertragen. Er speichert nichts und führt keine eigenen Logs. Als Hosting-Anbieter verarbeitet Cloudflare, Inc. technische Anfragedaten wie deine IP-Adresse, um den Dienst zu betreiben; siehe die Datenschutzerklärung von Cloudflare. Ohne Auth-Server-URL geht keine Anfrage an Cloudflare.
